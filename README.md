# Athena Queries

This repository contains a collection of useful Amazon Athena SQL queries for AWS troubleshooting, auditing, and operational analysis.

## Features

- Ready-to-use queries for common AWS services
- Helps with cost optimization and operational reporting
- Designed to save time on investigations and analysis

## Usage

1. Review the SQL scripts provided.
2. Copy and paste queries into your Amazon Athena console.
3. Modify as needed for your AWS environment.
